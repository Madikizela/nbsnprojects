# NBSN Mobile - Flutter App

A Flutter application for the National Building Skills Network (NBSN) mobile learning management system.

## Features

- Teacher Dashboard
- Learner Management
- Attendance Tracking
- Document Management
- Fingerprint Integration (planned)

## Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Android Studio / VS Code
- Android device or emulator

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

### Build for Android

```bash
flutter build apk --release
```

### Build for iOS

```bash
flutter build ios --release
```

## Project Structure

```
lib/
├── main.dart              # App entry point
├── screens/              # UI screens
├── models/               # Data models
├── services/             # API services
├── widgets/              # Reusable widgets
└── utils/                # Utility functions
```
